# 영수증 활동금액 자동 반영

연도 루트 폴더를 감시하다가 월 숫자가 가장 큰 `NN월_영수증` 폴더를 자동 선택합니다. 영수증 이미지가 추가되면 파일명에서 회원 이름과 월을 읽고, 이미지에서 가장 큰 원화 금액을 OCR로 인식하여 같은 달의 엑셀 파일에 반영합니다.

## 파일 규칙

- 영수증: `[주인공][O월]활동금액_이름.jpg`
- 엑셀: `O월_2026_주인공_회원별_활동_금액_목록.xlsx`
- 이름은 한글 3글자여야 합니다.
- 지원 이미지 형식은 `.jpg`, `.jpeg`, `.png`입니다.
- 엑셀에서 `이름`과 `활동금액` 헤더를 찾아 같은 이름의 활동금액 셀만 수정합니다.
- 월별 폴더는 `09월_영수증`, `10월_영수증` 형식을 사용합니다.
- 실행 중 더 큰 월의 폴더가 생성되면 해당 폴더로 자동 전환합니다.

## 설치

PowerShell에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 실행

기본 루트 경로는 `C:\Users\THE KE\Desktop\mjkim\주인공(AI동호회)\2026`이고 연도는 `2026`입니다. 이 경로에서 월 숫자가 가장 큰 `NN월_영수증` 폴더가 처리 대상이 됩니다.

```powershell
.\.venv\Scripts\python.exe .\receipt_agent.py
```

다른 연도 루트 또는 연도를 사용하려면 다음처럼 지정합니다.

```powershell
.\.venv\Scripts\python.exe .\receipt_agent.py --root "C:\연도별영수증\2026" --year 2026
```

현재 파일들을 한 번만 검사하고 종료하려면 `--once`, 엑셀을 실제로 수정하지 않고 결과만 확인하려면 `--dry-run`을 사용합니다.

```powershell
.\.venv\Scripts\python.exe .\receipt_agent.py --once --dry-run
```

## 동작 및 안전장치

- 새 이미지가 완전히 저장될 때까지 기다린 뒤 처리합니다.
- `NN월_영수증` 중 월 숫자가 가장 큰 폴더만 처리합니다. 예를 들어 `09월_영수증`과 `10월_영수증`이 있으면 `10월_영수증`을 사용합니다.
- 실행 중 `11월_영수증`이 생기면 다음 확인 주기에 자동으로 처리 대상을 전환합니다.
- 선택된 폴더의 월과 영수증 파일명의 월이 다르면 엑셀을 수정하지 않습니다.
- OCR 결과 중 천 단위 쉼표가 있거나 `원`이 붙은 10,000원 이상 금액만 후보로 삼고 가장 큰 금액을 사용합니다.
- 계좌번호처럼 쉼표와 `원`이 없는 긴 숫자는 무시합니다.
- 이름이 없거나 중복되면 엑셀을 수정하지 않습니다.
- Excel에서 대상 파일이 열려 있으면 수정하지 않고 로그에 오류를 남깁니다.
- Windows Excel 프로그램을 통해 값을 저장하므로 기존 인쇄 설정, 수식, 서식과 통합문서 구조를 보존합니다.
- 처리 이력은 현재 대상 월 폴더의 `logs\.receipt_agent_state.json`에 저장합니다.
- 실행 기록은 현재 대상 월 폴더의 `logs\receipt_agent.log`에 저장합니다.
- 처리 대상 월이 바뀌면 로그와 처리 이력 경로도 새 월의 `logs` 폴더로 자동 전환됩니다.
- 종료는 `Ctrl+C`입니다.

Windows 로그인 시 자동 실행이 필요하면 작업 스케줄러에 위 실행 명령을 등록할 수 있습니다.

Excel이 설치되지 않은 환경에서는 `--excel-backend openpyxl`을 사용할 수 있습니다. 이 방식은 일부 Excel 고유 기능을 보존하지 못할 수 있으므로 현재 Windows PC에서는 기본값인 `excel` 사용을 권장합니다.
